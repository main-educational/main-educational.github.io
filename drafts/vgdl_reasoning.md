## Overview

How do humans learn to play a new videogame in a few minutes, when reinforcement learning agents need millions of frames? This session introduces theory-based reinforcement learning, where agents learn intuitive theories of a game (objects, interactions and goals) using the Video Game Description Language (VGDL). It then examines how frontier large reasoning models (LRMs) learn new games, and how their behaviour and internal representations align with human players and their brain activity.

## Objectives

 * Learn the basics of theory-based reinforcement learning.
 * Discover the Video Game Description Language (VGDL), and how to write and play simple games with it.
 * Use a large reasoning model to play VGDL games, and compare its learning curve with human players.
